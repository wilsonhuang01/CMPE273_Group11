Implemented: provider-neutral model adapter with an Amazon Bedrock provider.

Performance, Memory and Architecture generators and Correctness/Critic reviewers can use MODEL_PROVIDER=bedrock (Converse API) or replay. Role prompts treat source as untrusted data; replies are parsed into the existing patch/review formats and revalidated. Calls have RPC-bounded timeouts, transient-only retries, bounded repair prompts and per-task call/token budgets. Failed automated tests and the deterministic risk gate are decided before any model call. Without credentials, the agent reports not ready and calls fail as UNAVAILABLE. Validated offline with stub/scripted-provider tests, and live on the Compose stack with Claude Sonnet 4.5 on Bedrock: for a program the starter rules do not recognize, all three generators produced patches that passed tests and sanitizers, both reviewers approved with evidence-bound reasoning, and the benchmark gate retained the baseline because the small example showed no reliable gain.
